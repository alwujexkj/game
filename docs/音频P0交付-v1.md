# 音频 P0 交付 v1（来自游戏音频）

## 目录
- SFX: `apps/web/public/audio/sfx/`
- E1 词: `apps/web/public/audio/words/e1/`
- 格式: ogg 主 + mp3 回退；44.1kHz mono；峰值约 -6～-3 dBFS

## P0 SFX
| 文件名 | 用途 | 时长 |
|---|---|---|
| sfx_ui_tap | UI 轻点 | 40–80ms |
| sfx_answer_correct | 答对 | 180–280ms |
| sfx_answer_wrong | 答错（温柔） | 220–350ms |
| sfx_heart_lose | 掉心 | 250–400ms |
| sfx_combo_up | 连击≥3 | 200–320ms |
| sfx_settle_clear | 结算通关 | 600–900ms |
| sfx_settle_star | 亮星 | 120–200ms |
| sfx_sticker_drop | 贴纸掉落 | 350–550ms |
| sfx_listen_replay | 再听反馈 | 60–100ms |

## E1 八词
word_apple, word_banana, word_cat, word_dog, word_fish, word_sun, word_book, word_water  
美式、约 0.9 语速、一词一遍；词前 80–120ms / 词后 150–200ms 静音。

## 接入注意
首触解锁 AudioContext；全局静音；TTS 仅作无预录时 fallback。
