# 《苏家学习乐园》V2 游戏设计总纲

> 来源：ChatGPT 分享「游戏开发岗位角色」对话整理（2026-09-07）  
> 用途：给总指导 / 各职能 Agent 的 V2 产品规格参考；**非 Wave0 范围**，Wave0 仍按现锁里程碑推进。

**项目定位：家庭冒险型学习游戏**

**核心理念：** 不是「让孩子来做题」，而是「为了完成游戏目标，自然使用数学、英语、科学、语文和生活知识」。

## 1. 项目现状（对话时点）

已有：数学馆 / 英语岛 / 单人小游戏 / 多设备组队 / 造关卡工坊 / 背包贴纸 / 家庭排行 / 家长总览 / Nest+Redis 可选 / 角色（甜甜·孟赢·孟辙·果冻）。

核心玩法：果冻数骨头、开门要几块、口算冲刺塔、听音找卡片、单词配对翻翻乐。

## 2. V2 总体目标

把「学习功能集合」升级成可持续游玩的「家庭冒险世界」。

核心循环：探索 → 发现事件 → 任务 → 冒险/小游戏 → 用知识解题 → 奖励 → 成长 → 解锁世界 → 家庭合作 → 创造 → 再探索。

## 3. 核心原则

游戏第一，学习第二。禁止「题目→答题→得星」裸循环；应是「目标→行动→遇问题→用知识→结果」。

## 4–5. 世界观与地图

家园中心 → 森林（数学）/ 海岛（英语）/ 太空港（科学）→ 神秘山（待解锁）。

功能入口升级为真实地点：数学馆→森林工程小屋；英语岛→语言港；组队→冒险者营地；工坊→创造者小镇；背包→家庭仓库；排行→家庭荣誉墙。

## 6–8. 家园 / 角色成长 / 能力树

家园可布置；角色有等级·经验·星·金币·收藏·称号。能力树：数学 / 语言 / 科学分支，能力影响机关、NPC、区域解锁。

## 9–18. 跨学科与内容

跨学科任务示例「拯救森林」：数学浇水总量 + 科学生长条件 + 英语 WATER/SUN/TREE + 语文短文。

数学升级为冒险能力、资源管理、应用/空间/逻辑，而非纯口算。英语场景化。科学互动实验。语文阅读成解谜。生活馆：金钱时间家务安全。

## 19–26. 任务 / 每日事件 / 合作 / AI

主线章节解锁区域；每日随机事件轻量无焦虑惩罚。多人升级信息不对称合作；家庭任务家长是队友。果冻 AI：分级提示禁止直接给答案。

## 27–33. 内容生成 / 工坊 / 收藏 / 宠物 / 奖励

AI 生成须规则校验。工坊 V2：孩子设计游戏并邀请家人。图鉴收藏。果冻饥饿心情亲密度。奖励分游戏/学习/创造三层。

## 34–37. 禁忌与家长端

禁：强制签到惩罚、氪金抽卡、排名羞辱、强制时长、广告。排行弱化名次强化个人成长与家庭共同成就。家长端从监控→家庭游戏控制台。

## 38–44. 循环与数据

日/周/月/长期循环；内容质量优先数量。统一 LearningContent / Quest / MiniGame / WorldEvent 等，避免每玩法自建题库。

## 45–48. 开发优先级

**P0：** 世界地图 · 角色成长 · Quest 框架 · 跨学科任务样板 · 统一奖励  
**P1：** 家园 · 宠物 · 每日事件 · 图鉴 · 合作冒险 · 家庭任务  
**P2：** AI NPC · 个性化推荐 · AI 关卡/故事 · 儿童创作平台  
**P3：** 完整家庭数字世界

## 49–54. 哲学与执行

一句话：不是把学习做成游戏皮，而是把学习过程变成可探索、成长、创造、与家人共同生活的世界。

给总指导：每加功能先问是否增加游戏性/探索/家庭互动/知识使用/长期成长/可重复/闭环；纯答题页降优先。

### 对话前文摘要：岗位拆解（7 角色）

游戏策划 · 教育/内容 · UI/美术 · 前端 · 后端 · QA · 产品/数据；适合 AI Agent 协作树（制作人→策划/美术/内容→Coding→前后端→QA→PR）。
